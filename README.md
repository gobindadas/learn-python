# Python Learning Journey: Basics to Advanced

Welcome to your comprehensive Python learning project! This repository is designed to take you from a complete beginner to an advanced Python programmer through structured lessons, practical examples, and hands-on exercises.

## How to Use This Repository

1. **Follow the order**: Start from Module 01 and progress sequentially
2. **Read the theory**: Each module has a README.md explaining concepts
3. **Study examples**: Run the examples.py file to see concepts in action
4. **Practice**: Complete exercises.py before checking solutions.py
5. **Build projects**: Apply your knowledge in the Projects section

## Learning Path

### Phase 1: Foundations (Weeks 1-2)
- **[Module 01: Python Basics](./01_Basics/)** - Variables, data types, operators, I/O
- **[Module 02: Control Flow](./02_Control_Flow/)** - Conditionals, loops, logic
- **[Module 03: Data Structures](./03_Data_Structures/)** - Lists, tuples, dictionaries, sets

### Phase 2: Building Blocks (Weeks 3-4)
- **[Module 04: Functions](./04_Functions/)** - Function basics, parameters, scope, lambda
- **[Module 05: Modules & Packages](./05_Modules_and_Packages/)** - Importing, creating modules, pip
- **[Module 06: File Handling](./06_File_Handling/)** - Reading/writing files, CSV, JSON

### Phase 3: Advanced Concepts (Weeks 5-6)
- **[Module 07: Object-Oriented Programming](./07_OOP/)** - Classes, objects, inheritance
- **[Module 08: Error Handling](./08_Error_Handling/)** - Exceptions, debugging
- **[Module 09: Advanced Topics](./09_Advanced_Topics/)** - Decorators, generators, comprehensions

### Phase 4: Practice (Ongoing)
- **[Module 10: Projects](./10_Projects/)** - Real-world projects to solidify your skills

## Quick Start

```bash
# Navigate to the first module
cd 01_Basics

# Read the theory
cat README.md

# Run examples
python3 examples.py

# Try exercises
python3 exercises.py

# Check solutions (only after trying!)
python3 solutions.py
```

## Prerequisites

- Python 3.8 or higher installed
- A text editor or IDE (VS Code, PyCharm, or any editor you prefer)
- Curiosity and dedication!

## Tips for Success

1. **Type the code yourself** - Don't copy-paste, type to build muscle memory
2. **Experiment** - Modify examples to see what happens
3. **Practice daily** - Even 30 minutes daily is better than 3 hours once a week
4. **Debug errors** - Errors are learning opportunities, not failures
5. **Build things** - Apply concepts to small projects as you learn

## Getting Help

When stuck:
1. Read error messages carefully
2. Use `help()` function in Python
3. Search the error message online
4. Review the examples again
5. Take a break and come back with fresh eyes

Happy coding! Remember, every expert was once a beginner.
