# Advanced Topics - Interview Questions

## Level: Normal (1-5)

### Question 1: Comprehensions
Write dict, set, and nested list comprehensions.

### Question 2: Lambda Functions
When should you use lambda vs def? Show examples.

### Question 3: Map, Filter, Reduce
Compare these functional programming tools vs comprehensions.

### Question 4: *args and **kwargs Unpacking
Show different ways to use unpacking operators.

### Question 5: Ternary Operator
Write complex conditional expressions using ternary operator.

## Level: Medium (6-10)

### Question 6: Iterators and Iterables
Implement custom iterator and iterable classes.

### Question 7: Context Managers
Create a context manager using both class and @contextmanager.

### Question 8: Regular Expressions
Write regex for email validation, phone numbers, and URL parsing.

### Question 9: Type Hints
Use type hints with generics, Optional, Union, List, Dict.

### Question 10: Protocols (Python 3.8+)
Implement structural subtyping using Protocol.

## Level: Hard (11-15)

### Question 11: Coroutines and async/await
Implement async functions, gather, and create_task.

### Question 12: Metaclasses Deep Dive
Use metaclasses to implement automatic property creation.

### Question 13: Memory Management
Explain reference counting, garbage collection, and `__del__`.

### Question 14: Performance Optimization
Use timeit, profile, and line_profiler to optimize code.

### Question 15: C Extensions
When would you use C extensions? Explain ctypes and cffi.
