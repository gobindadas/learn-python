# Object-Oriented Programming - Interview Questions

## Level: Normal (1-5)

### Question 1: Class vs Instance Attributes
Explain the difference between class attributes and instance attributes.

### Question 2: `__init__` vs `__new__`
What's the difference between `__init__` and `__new__`?

### Question 3: Inheritance
What is inheritance? Show single and multiple inheritance examples.

### Question 4: Method Types
Explain instance methods, class methods (@classmethod), and static methods (@staticmethod).

### Question 5: Encapsulation
How does Python implement encapsulation? Explain private attributes (single and double underscore).

## Level: Medium (6-10)

### Question 6: Property Decorator
What is the `@property` decorator? Implement getters, setters, and deleters.

### Question 7: Magic Methods
Implement `__str__`, `__repr__`, `__len__`, `__getitem__` for a custom class.

### Question 8: Abstract Base Classes
What are ABCs? Create an abstract class using `abc` module.

### Question 9: Method Resolution Order (MRO)
Explain Python's MRO. What is the C3 linearization algorithm?

### Question 10: Composition vs Inheritance
When should you use composition over inheritance?

## Level: Hard (11-15)

### Question 11: Metaclasses
What are metaclasses? Implement a custom metaclass.

### Question 12: Descriptor Protocol
Implement a descriptor class with `__get__`, `__set__`, and `__delete__`.

### Question 13: Singleton Pattern
Implement the Singleton pattern in Python (multiple ways).

### Question 14: Context Manager Protocol
Implement `__enter__` and `__exit__` for a custom context manager.

### Question 15: Operator Overloading
Implement a Vector class with `__add__`, `__mul__`, `__eq__`, etc.
