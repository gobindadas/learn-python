# Multithreading and Concurrency - Interview Questions

## Level: Normal (1-5)

### Question 1: Threading vs Multiprocessing
Explain GIL and when to use threading vs multiprocessing.

### Question 2: Thread Creation
Create threads using Thread class and compare with concurrent.futures.

### Question 3: Thread Synchronization
What are Locks, RLocks, and Semaphores? When to use each?

### Question 4: Race Conditions
What is a race condition? Demonstrate and fix one.

### Question 5: Daemon Threads
What are daemon threads? When should you use them?

## Level: Medium (6-10)

### Question 6: Producer-Consumer Pattern
Implement producer-consumer using Queue.

### Question 7: ThreadPoolExecutor
Compare ThreadPoolExecutor vs ProcessPoolExecutor.

### Question 8: Deadlock
What causes deadlock? How do you prevent it?

### Question 9: Event and Condition
Use Event and Condition for thread communication.

### Question 10: Async vs Threads
When to use asyncio vs threading?

## Level: Hard (11-15)

### Question 11: Thread-Safe Singleton
Implement thread-safe singleton pattern.

### Question 12: Lock-Free Data Structures
Implement lock-free queue using atomic operations.

### Question 13: Concurrent File Processing
Process multiple files concurrently with error handling.

### Question 14: Rate Limiting
Implement thread-safe rate limiter.

### Question 15: Worker Pool Pattern
Implement custom worker pool with task queue.
