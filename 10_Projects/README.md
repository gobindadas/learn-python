## Project Guidelines

### Before You Start
1. **Plan first**: Write out features and requirements
2. **Break it down**: Divide into smaller, manageable tasks
3. **Start simple**: Get basic version working first
4. **Iterate**: Add features one at a time

### Project Structure
```
project_name/
├── main.py          # Entry point
├── modules/         # Your custom modules
│   ├── __init__.py
│   └── helper.py
├── data/            # Data files
│   └── data.json
└── README.md        # Project description
```

### Best Practices
- **Use functions**: Break code into reusable functions
- **Add comments**: Explain complex logic
- **Handle errors**: Don't let program crash
- **Test thoroughly**: Try edge cases
- **Version control**: Use Git to track changes
