# Projects - Interview Questions

## Level: Normal (1-5)

### Question 1: Project Structure
Design a proper Python project structure with tests, docs, and configuration files.

### Question 2: Virtual Environments
Why use virtual environments? How do you create and manage them?

### Question 3: Requirements Management
Explain requirements.txt vs requirements-dev.txt vs setup.py dependencies.

### Question 4: Configuration Management
How do you manage configuration across development, staging, and production?

### Question 5: Logging Setup
Set up proper logging with file rotation and different log levels.

## Level: Medium (6-10)

### Question 6: CLI Application
Build a command-line application with argument parsing using argparse or click.

### Question 7: REST API
Create a REST API using Flask or FastAPI with proper error handling.

### Question 8: Database Integration
Integrate SQLite/PostgreSQL with proper connection pooling and migrations.

### Question 9: Testing Strategy
Implement unit tests, integration tests, and mocking strategies.

### Question 10: Continuous Integration
Set up CI/CD pipeline with GitHub Actions or GitLab CI.

## Level: Hard (11-15)

### Question 11: Microservices Architecture
Design a microservices system with inter-service communication.

### Question 12: Performance Monitoring
Implement APM (Application Performance Monitoring) with metrics and tracing.

### Question 13: Security Best Practices
Implement authentication, authorization, input validation, and SQL injection prevention.

### Question 14: Scalability Patterns
Implement caching, load balancing, and horizontal scaling.

### Question 15: Production Deployment
Deploy application with Docker, Kubernetes, and implement health checks.
