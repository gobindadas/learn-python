# File Handling - Interview Questions

## Level: Normal (1-5)

### Question 1: File Opening Modes
Explain the difference between 'r', 'w', 'a', 'r+', 'w+', 'rb', 'wb' modes.

### Question 2: Context Managers
Why should you use `with` statement when working with files?

### Question 3: Reading Methods
Compare: `read()`, `readline()`, `readlines()`, and iteration.

### Question 4: File Paths
How do you work with file paths in a cross-platform way?

### Question 5: File Existence Check
How do you check if a file exists before opening it?

## Level: Medium (6-10)

### Question 6: Large File Processing
How do you efficiently process a 10GB file without loading it all into memory?

### Question 7: CSV vs JSON
When would you choose CSV over JSON or vice versa? Demonstrate both.

### Question 8: Binary Files
How do you read and write binary files? Provide examples with images or pickle.

### Question 9: File Locking
How do you handle concurrent file access? Implement file locking.

### Question 10: Temporary Files
When and how should you use temporary files? Use `tempfile` module.

## Level: Hard (11-15)

### Question 11: Memory-Mapped Files
What are memory-mapped files? When would you use `mmap`?

### Question 12: Atomic File Writes
Implement an atomic file write operation (write-then-rename pattern).

### Question 13: File Watching
Implement a file watcher that monitors directory changes.

### Question 14: Custom File Format
Design and implement a custom binary file format with header and data sections.

### Question 15: File Compression
How do you work with compressed files (gzip, zip, tar)? Implement streaming decompression.
